# Agentic video editing

Video-editing skills for Claude Code (see README.md). The people using this folder are usually not programmers.

- If they ask to set up video editing, or a tool is missing (ffmpeg, Python, mlx-whisper, the skills), follow `SETUP.md` step by step.
- The skills only work once they're copied into `~/.claude/skills/` (SETUP.md step 8), and only in sessions started after that. If the skills aren't installed yet, set them up first instead of editing from this folder.
